## What KalzTunz Does

| Feature | Description |
|---|---|
| 🎸 **Chord Extraction** | Upload any MP3/WAV/FLAC/video — get key, BPM, full chord timeline with confidence scores |
| 🤖 **AI Generation** | Genre → Mood → Key → Instruments → chord progressions with Roman numerals and scale analysis |
| 🎵 **Music Discovery** | Search 100 million Spotify tracks, browse by genre/mood, play 30-second previews |
| 📂 **Personal Library** | Save extractions and generations, build playlists, follow artists, offline-capable |
| 📄 **Sheet Music PDF** | Export professional A4 PDFs with real staff notation, bars, treble clef, chord boxes |
| 🔊 **In-browser Player** | Play/pause/seek generated progressions and uploaded files using Web Audio API |

## Architecture — Single Service

FastAPI serves both the REST API **and** the built React frontend from one process on one port. No CORS headaches, no split domains.

```
Browser → https://kalztunz.onrender.com
              │
              ├── /api/*           → FastAPI routes
              ├── /health          → health check
              ├── /uploads/*       → user file storage
              └── /*               → React SPA (index.html)
```

## Quick Start

### Option 1 — Docker (recommended)

```bash
git clone https://github.com/yourname/kalztunz.git
cd kalztunz

# Copy and configure env
cp .env.example .env
# Set SECRET_KEY, DATABASE_URL, REDIS_URL, Spotify keys etc.

docker-compose up --build
# Open http://localhost:8000
```

### Option 2 — Local Dev (hot reload)

```bash
# 1. Python deps
pip install --only-binary=scipy -r requirements.txt

# 2. Database
alembic upgrade head

# 3. Backend (Terminal 1)
uvicorn app:app --reload --port 8000

# 4. Frontend dev server (Terminal 2)
cd frontend && npm install && npm run dev
# Open http://localhost:5173 (proxies /api → :8000)
```

### Option 3 — Build & Serve Unified

```bash
# Build React into ./dist (served by FastAPI)
cd frontend && npm install && npm run build && cd ..

# Start single service
uvicorn app:app --host 0.0.0.0 --port 8000
# Open http://localhost:8000
```

## Deploy to Render

1. **Fork / push** this repo to GitHub
2. In [Render dashboard](https://dashboard.render.com) → **New Web Service** → connect repo
3. Render reads `render.yaml` automatically — it will provision:
   - Web service (FastAPI + React build)
   - Background worker (RQ chord extraction)
   - PostgreSQL database
   - Redis instance
4. Set the **secret** env vars in Render dashboard:

| Variable | Where to get it |
|---|---|
| `SPOTIFY_CLIENT_ID` | [Spotify Developer Dashboard](https://developer.spotify.com/dashboard) |
| `SPOTIFY_CLIENT_SECRET` | Same |
| `GOOGLE_CLIENT_ID` | [Google Cloud Console](https://console.cloud.google.com) → OAuth 2.0 |
| `GOOGLE_CLIENT_SECRET` | Same |
| `GITHUB_CLIENT_ID` | [GitHub Settings](https://github.com/settings/developers) → OAuth Apps |
| `GITHUB_CLIENT_SECRET` | Same |

> `SECRET_KEY` and `DATABASE_URL` are auto-generated by Render from `render.yaml`.

```env
ENVIRONMENT=production
DATABASE_URL=postgresql://user:pass@host:5432/kalztunz

```

## API Reference

### Auth
| Method | Path | Description |
|---|---|---|
| `POST` | `/api/auth/register` | Create account |
| `POST` | `/api/auth/login` | Get JWT token |
| `GET`  | `/api/auth/me` | Current user |
| `PATCH`| `/api/auth/profile` | Update username/bio/location/website |
| `POST` | `/api/auth/avatar` | Upload profile picture (data URL or https://) |
| `GET`  | `/api/auth/refresh` | Refresh access token |
| `GET`  | `/api/auth/google` | Google OAuth redirect |
| `GET`  | `/api/auth/github` | GitHub OAuth redirect |

### Audio
| Method | Path | Description |
|---|---|---|
| `POST` | `/api/extract-chords` | Submit audio file for chord extraction |
| `POST` | `/api/generate` | Generate chord progressions |
| `GET`  | `/api/jobs/{id}` | Poll job status and result |
| `GET`  | `/api/demo/chords` | Demo extraction (no file needed) |

### Spotify
| Method | Path | Description |
|---|---|---|
| `GET` | `/api/spotify/search` | Search tracks/artists/albums |
| `GET` | `/api/spotify/artist/{id}` | Artist details + top tracks |
| `GET` | `/api/spotify/status` | Check Spotify API connectivity |
